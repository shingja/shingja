## 关于我

<img src="assets/sticker-gear.gif?v=4" alt="" width="56" align="right">

我是 **shingja**，北科大机械 2024 级。

一个喜欢把想法做成实物、再拆开研究为什么能跑的人。做过机械结构、嵌入式、仿真，也写过一些自己会用的小工具。比赛拿过几个奖，更多时候是在和 bug、装配公差、deadline 打架。

这里放项目经验、踩坑记录和能直接拿去用的模板。要是能帮你少熬一个通宵，就值了。

碰到过 CAD/CAE、嵌入式、仿真、编程、文档这些领域，缺什么就学什么，学完就拿去用。

个人独立开发，习惯从零把想法做成能跑的东西。

喜欢《孤独摇滚！》。
